Для работы с проектом необходимы следующие инструменты:

✓ NASM          - Ассемблер для x86
✓ GCC           - Компилятор C с поддержкой 32-bit (-m32)
✓ LD            - Линкер GNU
✓ Make          - Система сборки
✓ QEMU          - Эмулятор x86 (qemu-system-i386)
✓ GRUB          - Загрузчик (grub-mkrescue)
✓ xorriso       - Создание ISO образов
✓ mtools        - Утилиты для FAT

Все инструменты устанавливаются автоматически через setup.sh

═══════════════════════════════════════════════════════════════════

⚠️  ВНИМАНИЕ: Ты работаешь на Windows (win32)!

Все скрипты (.sh файлы) предназначены для Linux.
Для работы на Windows есть несколько вариантов:

1. WSL (Windows Subsystem for Linux) - РЕКОМЕНДУЕТСЯ
   ─────────────────────────────────────────────────
   • Установи WSL2 с Ubuntu
   • Скопируй проект в WSL
   • Запусти setup.sh в WSL
   • Все команды будут работать нативно

2. MSYS2 / MinGW
   ─────────────────────────────────────────────────
   • Установи MSYS2
   • Установи пакеты: mingw-w64-x86_64-gcc, nasm, make
   • QEMU для Windows
   • Адаптируй скрипты под Windows

3. Виртуальная машина с Linux
   ─────────────────────────────────────────────────
   • Установи VirtualBox/VMware
   • Создай VM с Ubuntu/Debian
   • Работай в Linux окружении
