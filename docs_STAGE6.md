## Как работает PIT

**PIT (Programmable Interval Timer)** - это аппаратный таймер, который генерирует прерывания IRQ0 с заданной частотой.

### Параметры:
- **Базовая частота**: 1,193,182 Hz
- **Настроенная частота**: 100 Hz (10 ms на тик)
- **Прерывание**: IRQ0 (INT 32)
- **Порты**: 0x40-0x43

### Формула делителя:
```
Делитель = Базовая частота / Желаемая частота
Делитель = 1193182 / 100 = 11931
```

## Реализованные функции

- `timer_init()` - инициализация таймера
- `timer_get_ticks()` - получение количества тиков
- `timer_get_uptime_ms()` - время работы в миллисекундах
- `timer_get_uptime_sec()` - время работы в секундах
- `timer_sleep(ms)` - задержка в миллисекундах
- `timer_wait(ticks)` - задержка в тиках
- `timer_get_frequency()` - получение частоты таймера
