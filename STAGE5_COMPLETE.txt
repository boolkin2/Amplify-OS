Процесс обработки нажатия клавиши:
───────────────────────────────────

1. Пользователь нажимает клавишу
   ↓
2. Клавиатура генерирует IRQ1
   ↓
3. Процессор вызывает keyboard_irq_handler()
   ↓
4. Чтение скан-кода из порта 0x60
   ↓
5. Определение: нажатие или отпускание (bit 7)
   ↓
6. Обработка модификаторов (Shift, Ctrl, Alt, Caps Lock)
   ↓
7. Преобразование скан-кода в ASCII
   ↓
8. Добавление символа в кольцевой буфер
   ↓
9. Приложение читает символ через keyboard_getchar()

Кольцевой буфер:
────────────────

┌───┬───┬───┬───┬───┬───┬───┬───┐
│ H │ e │ l │ l │ o │   │   │   │ ... (256 элементов)
└───┴───┴───┴───┴───┴───┴───┴───┘
  ↑                   ↑
  read_pos            write_pos

Когда write_pos достигает конца → возврат к началу (кольцевой)

Таблицы скан-кодов:
───────────────────

scancode_to_ascii[128]        - без Shift
scancode_to_ascii_shift[128]  - с Shift

Примеры:
  0x1E → 'a' (без Shift) или 'A' (с Shift)
  0x02 → '1' (без Shift) или '!' (с Shift)
  0x1C → '\n' (Enter)
  0x0E → '\b' (Backspace)

═══════════════════════════════════════════════════════════════════
  API ДРАЙВЕРА
═══════════════════════════════════════════════════════════════════

void keyboard_init(void)
  Инициализирует драйвер, регистрирует IRQ1

char keyboard_getchar(void)
  Блокирующее чтение символа (ожидает нажатия)

char keyboard_getchar_nonblock(void)
  Неблокирующее чтение (возвращает 0 если буфер пуст)

int keyboard_gets(char* buffer, int max_len)
  Чтение строки до Enter (с поддержкой Backspace)

bool keyboard_has_key(void)
  Проверка наличия символа в буфере

keyboard_state_t keyboard_get_state(void)
  Получение состояния модификаторов

void keyboard_clear_buffer(void)
  Очистка буфера клавиатуры
