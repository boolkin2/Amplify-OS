IDT (Interrupt Descriptor Table):
──────────────────────────────────

┌─────────────────────────────────────────────────────────────┐
│ Номер │ Тип │ Описание                                      │
├─────────────────────────────────────────────────────────────┤
│  0-31 │ ISR │ Исключения CPU                                │
│       │     │ - 0: Деление на ноль                          │
│       │     │ - 13: General Protection Fault                │
│       │     │ - 14: Page Fault                              │
│       │     │ - и другие                                    │
├─────────────────────────────────────────────────────────────┤
│ 32-47 │ IRQ │ Аппаратные прерывания                         │
│       │     │ - 32 (IRQ0): Системный таймер                 │
│       │     │ - 33 (IRQ1): Клавиатура                       │
│       │     │ - 44 (IRQ12): PS/2 мышь                       │
│       │     │ - и другие                                    │
├─────────────────────────────────────────────────────────────┤
│ 48-255│  -  │ Зарезервировано (пользовательские)            │
└─────────────────────────────────────────────────────────────┘

Процесс обработки прерывания:
──────────────────────────────

1. Событие (исключение или IRQ)
   ↓
2. Процессор ищет обработчик в IDT
   ↓
3. Процессор сохраняет EIP, CS, EFLAGS
   ↓
4. Вызов isr0-31 или irq0-15 (asm)
   ↓
5. Сохранение всех регистров (PUSHA)
   ↓
6. Вызов isr_handler() или irq_handler() (C)
   ↓
7. Вызов пользовательского обработчика (если есть)
   ↓
8. Для IRQ: отправка EOI в PIC
   ↓
9. Восстановление регистров (POPA)
   ↓
10. IRET - возврат из прерывания

PIC (Programmable Interrupt Controller):
─────────────────────────────────────────

Главный PIC (IRQ 0-7):
  Порты: 0x20 (команды), 0x21 (данные)
  Переназначен на прерывания 32-39

Подчинённый PIC (IRQ 8-15):
  Порты: 0xA0 (команды), 0xA1 (данные)
  Переназначен на прерывания 40-47
  Подключён к IRQ2 главного PIC

EOI (End Of Interrupt):
  После обработки IRQ отправляется команда 0x20:
  - IRQ 0-7:  outb(0x20, 0x20)
  - IRQ 8-15: outb(0xA0, 0x20) + outb(0x20, 0x20)

Пример использования:

#include "arch/i386/isr.h"

// Обработчик клавиатуры
void keyboard_handler(registers_t* regs) {
    uint8_t scancode = inb(0x60);
    // Обработка скан-кода
}

// Регистрация
void init_keyboard(void) {
    isr_register_handler(IRQ1, keyboard_handler);
}

// Удаление
void shutdown_keyboard(void) {
    isr_unregister_handler(IRQ1);
}
