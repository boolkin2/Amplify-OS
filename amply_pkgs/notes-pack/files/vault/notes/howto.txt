Как пользоваться Amply
=======================

1) Amply list — посмотреть, что установлено.
2) Amply search welcome — найти пакеты в репозитории.
3) Amply install cyber-theme — установить тему (заодно
   притянет welcome как зависимость).
4) Amply remove cyber-theme — удалить тему.
5) Amply verify cyber-theme — проверить целостность.
6) Amply upgrade — обновить все пакеты.

Если пакет требует подкаталога /disk/<X>/<Y>/<Z>/...,
он будет создан автоматически (этап 45 добавил поддержку
подкаталогов и Long File Names в FAT32).
