# ui_mockups/ — макеты интерфейса для AI-генератора

Положите сюда PNG/JPG-скриншоты или рисунки того, как вы хотите видеть
рабочий стол MyOS. При следующем `make` Python-скрипт `tools/ai_ui_gen.py`
проанализирует эти картинки и сгенерирует:

- `kernel/gui/ui_theme.h`    — цвета фона рабочего стола и панели задач
- `kernel/gui/ui_layout.inc` — порядок иконок, их цвета и символы

## Что именно распознаётся

1. **Цвет фона рабочего стола** (градиент «сверху вниз»)
2. **Цвет панели задач**
3. **Порядок 8 встроенных приложений** слева-направо, сверху-вниз:
   `Calc, Clock, Paint, Term, Info, About, Notes, Panel`
4. **Цвет каждой иконки-плитки**
5. **Символ-глиф** на иконке (1–2 ASCII-символа)

Добавить **новое приложение** через макет нельзя — callback'и приложений
static в `apps.c`. Этап 23 меняет только внешний вид/компоновку уже
существующих приложений.

## Режимы работы генератора

Скрипт последовательно пробует три способа:

1. **Claude Vision API** (лучший результат).
   Установите переменную окружения:
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```
   Затем `make`. Скрипт пошлёт до 4 макетов в Claude Sonnet и получит JSON.

2. **Pillow-эвристика** (локально, без интернета).
   ```bash
   pip3 install -r tools/ai_ui_gen_requirements.txt
   ```
   Определяется только **цветовая тема** — порядок иконок остаётся
   дефолтным.

3. **Safe default** — если ни API-ключа, ни Pillow нет (или скрипт упал).
   Сборка ОС **никогда не ломается** из-за отсутствия AI.

## Формат файлов

Любой PNG/JPG/JPEG/BMP/WEBP. Оптимально: 1024×768 (совпадает с
разрешением VESA в MyOS), 4 МБ максимум.

## Пример вручную

```bash
python3 tools/ai_ui_gen.py
```

Скрипт выведет в stderr, какой режим был использован и куда записал файлы.
