═══════════════════════════════════════════════════════════════════
  АРХИТЕКТУРА ЗАГРУЗКИ
═══════════════════════════════════════════════════════════════════

1. BIOS/UEFI
   ↓
2. GRUB (читает Multiboot header)
   ↓
3. boot.asm (_start)
   - EAX = 0x2BADB002 (Multiboot magic)
   - EBX = адрес multiboot_info_t
   - Настройка ESP (stack pointer)
   - push ebx, push eax
   - call kernel_main
   ↓
4. kernel.c (kernel_main)
   - Инициализация VGA
   - Вывод информации
   - halt (остановка процессора)

═══════════════════════════════════════════════════════════════════
  ТЕХНИЧЕСКИЕ ДЕТАЛИ
═══════════════════════════════════════════════════════════════════

Multiboot Header:
─────────────────
  Magic:     0x1BADB002
  Flags:     0x00000003 (align + meminfo)
  Checksum:  -(magic + flags)
  Размещение: Первые 8KB файла (секция .multiboot)

VGA Text Mode:
──────────────
  Адрес:     0xB8000
  Размер:    80x25 символов (2000 символов)
  Формат:    [ASCII byte][Attribute byte]
  Атрибут:   [4 bit BG][4 bit FG]
  Цвета:     16 цветов (0-15)

Стек:
─────
  Размер:    16384 байт (16KB)
  Направление: Вниз (от stack_top к stack_bottom)
  Размещение: Секция .bss

Память:
───────
  Ядро загружается по адресу: 1MB (0x00100000)
  Секции: .multiboot, .text, .rodata, .data, .bss

═══════════════════════════════════════════════════════════════════
  КОМАНДЫ ДЛЯ СБОРКИ (Linux)
═══════════════════════════════════════════════════════════════════

Быстрый запуск:
───────────────
make run              # Сборка + запуск в QEMU

Пошаговая сборка:
──────────────────
make                  # Только сборка
make clean            # Очистка
make debug            # Запуск с отладкой GDB

Ручная сборка:
──────────────
# 1. Ассемблер
nasm -f elf32 kernel/arch/i386/boot.asm -o build/kernel/arch/i386/boot.o

# 2. Компиляция C
gcc -m32 -ffreestanding -O2 -Wall -Wextra -fno-exceptions -fno-pie \
    -fno-stack-protector -c kernel/kernel.c -o build/kernel/kernel.o

gcc -m32 -ffreestanding -O2 -Wall -Wextra -fno-exceptions -fno-pie \
    -fno-stack-protector -c kernel/vga.c -o build/kernel/vga.o

# 3. Линковка
ld -m elf_i386 -T linker.ld -nostdlib \
   -o build/kernel.bin \
   build/kernel/arch/i386/boot.o \
   build/kernel/kernel.o \
   build/kernel/vga.o

# 4. Создание ISO
cp build/kernel.bin iso/boot/kernel.bin
cp boot/grub.cfg iso/boot/grub/grub.cfg
grub-mkrescue -o build/myos.iso iso/

# 5. Запуск
qemu-system-i386 -cdrom build/myos.iso -m 128M

❌ Проблема: "multiboot header not found"
✓ Решение: Проверь что секция .multiboot первая в linker.ld

❌ Проблема: Чёрный экран в QEMU
✓ Решение: Проверь что ISO создан, запусти с -d int,cpu_reset

❌ Проблема: "undefined reference to __stack_chk_fail"
✓ Решение: Добавь -fno-stack-protector в CFLAGS

❌ Проблема: Ошибки компиляции на Windows
✓ Решение: Используй WSL2, MSYS2 или Linux VM

❌ Проблема: "Error 13: Invalid executable format"
✓ Решение: Проверь флаги линковки (-m elf_i386)
