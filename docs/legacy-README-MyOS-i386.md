# MyOS v2.0 — Операционная система с нуля

> 32-битная операционная система для архитектуры x86, написанная с нуля на C и Assembly.
> Графический интерфейс с оконным менеджером, мышью, 6 встроенных приложений, многозадачность и Ring 3.

---

## 🖥️ Возможности

### Ядро
- **Загрузчик**: GRUB Multiboot
- **Режим**: Protected Mode (32-bit x86)
- **GDT/IDT**: Глобальная и локальная таблицы дескрипторов
- **Прерывания**: IRQ обработка, ISR, системные вызовы (int 0x80)
- **Таймер**: PIT 100 Hz, функции задержки
- **Многозадачность**: Preemptive Round-Robin планировщик
- **Ring 3**: Пользовательские приложения в непривилегированном кольце

### Память
- **PMM**: Physical Memory Manager (bitmap)
- **Heap**: kmalloc/kfree с алгоритмом First-Fit
- **Paging**: Виртуальная память, page fault handler
- **Identity Mapping**: Первые 16 MB + фреймбуфер

### Файловая система
- **VFS**: Virtual File System (абстрактный интерфейс)
- **InitRD**: RAM-диск, загружаемый как Multiboot-модуль

### Графика
- **VESA Framebuffer**: 1024×768×32 бит (линейный фреймбуфер)
- **Double Buffering**: Рендеринг без мерцания
- **Графические примитивы**: Линии, прямоугольники, окружности, градиенты
- **Bitmap-шрифт**: 8×16 пикселей, 256 символов (CP437)

### GUI — Оконный менеджер
- **Окна**: Создание, перемещение (drag), закрытие (кнопка ✕)
- **Z-order**: Фокусировка, вывод на передний план
- **Рабочий стол**: Градиентный фон, иконки приложений
- **Панель задач**: Кнопка Start, открытые окна, часы (uptime)
- **Мышь**: PS/2 драйвер, графический курсор

### Встроенные приложения
| Приложение | Описание |
|---|---|
| **Calculator** | Калькулятор с кнопками 0-9, +, -, ×, ÷, = |
| **Clock** | Системные часы (uptime в формате HH:MM:SS) |
| **Paint** | Рисование мышью с палитрой из 10 цветов |
| **Terminal** | Имитация терминала с мигающим курсором |
| **System Info** | Информация о памяти, архитектуре, uptime |
| **About** | О системе MyOS |

### Звук
- **PC Speaker**: Мелодия при загрузке (C5→E5→G5→C6)

### Загрузка
- **Splash Screen**: Анимированный загрузочный экран с логотипом и прогресс-баром

## 🚀 Сборка и запуск

### Зависимости

```bash
# Ubuntu / Debian
sudo apt install gcc nasm ld grub-mkrescue xorriso qemu-system-x86

# Arch Linux
sudo pacman -S gcc nasm grub xorriso qemu
```

### Сборка

```bash
# Сборка всего проекта (ядро + initrd + ISO)
make

# Сборка и запуск в QEMU (со звуком PC Speaker)
make run

# Запуск без звука (если SDL аудио недоступен)
make run-nosound

# Режим отладки (QEMU + GDB)
make debug

# Очистка
make clean

# Информация о проекте
make info
```

### Одна команда для всего:

```bash
make run
```

## 🎮 Управление

- **Мышь**: перемещение курсора, клик по иконкам/окнам
- **Перетаскивание окон**: зажмите заголовок окна и тяните
- **Закрытие окна**: нажмите красную кнопку ✕ в правом верхнем углу
- **Калькулятор**: кликайте по кнопкам
- **Paint**: выберите цвет, рисуйте мышью в области холста
- **Клавиатура**: работает в текстовом режиме (shell)
